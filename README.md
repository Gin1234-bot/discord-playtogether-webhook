# Play Together Giftcode Tracker 24/7 (Discord Webhook)

Hệ thống tự động săn và thông báo mã Giftcode Play Together (VNG & Quốc tế) 24/7 qua Discord Webhook, hoàn toàn không cần đăng nhập hay dùng nick clone Facebook.

## Tính Năng Nổi Bật
- **Zero-Login Architecture**: Thu thập mã code tự động từ các nguồn phân tích thời gian thực mà không cần tài khoản Facebook.
- **Phát hiện mã mới tức thì**: Tự động so sánh với `seen_codes.json`, chỉ phát thông báo khi có mã code mới tinh (không spam tin cũ).
- **Trải nghiệm 1-click copy**: Mã code được định dạng trong khung code để thành viên trên điện thoại và máy tính chỉ cần bấm 1 chạm là sao chép được ngay.
- **Đính kèm cổng đổi code**: Tích hợp sẵn đường link chuyển thẳng đến cổng nhập code chính thức của VNG (`giftcode.vnggames.com/vn/redeem`) và HAEGIN Quốc tế.
- **Chạy tự động 24/7 (0đ)**: Tích hợp với GitHub Actions chạy định kỳ mỗi 30 phút.
